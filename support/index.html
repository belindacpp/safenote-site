支持与帮助

遇到问题时，请先保留 App 和现有备份，再根据下面的方法排查。

中文
  1. 无法解锁：输入设置在本机的应用锁密码。Face ID / Touch ID 只是快捷解锁方式，仍可使用密码。
  2. 相机或照片不可用：检查系统“设置 → 随时记”的权限。拒绝权限不影响文字笔记。
  3. 导出备份：在 App 中打开“设置 → 备份与恢复”，生成加密备份，单独保存恢复码，重新输入恢复码后将文件保存到“文件”。
  4. 换机恢复：先把备份文件放到新设备可访问的位置，在欢迎页或“设置 → 备份与恢复”中选择文件并输入对应恢复码。恢复会创建独立资料库，无需登录账号。
  5. 数据异常：不要先卸载 App。保留设备和现有备份，记录发生时间与复现步骤，然后联系支持。

English
  1. Unlock: enter the app passcode set on this device. Face ID / Touch ID is a shortcut; the passcode remains available.
  2. Camera or photos: check permissions in iOS Settings → SafeNote. Text notes work without these permissions.
  3. Export a backup: open Settings → Backup & Restore in the app, create an encrypted backup, keep the recovery code separately, confirm the code, and save the file through Files.
  4. Restore on another device: make the backup file available to the new device, select it from the welcome screen or Settings → Backup & Restore, and enter its recovery code. Restore creates a separate local library. No account is needed.
  5. Data trouble: keep the app installed. Preserve the device and any backups, note when the problem occurred, and contact support.
